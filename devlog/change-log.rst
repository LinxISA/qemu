
LinxBlockISA Change Log
========================

版本号：v0.1
-------------
发布时间：2022-01-29 17:20
说明：该版本基于 BlockISA基础指令集涉及文档 v0.11

已实现：

  1. 标准标量块指令，对应基础指令集。
  2. 系统指令中实现了 sysget/sysset，ebreak，mret，fence(空)，sret。

待实现：

  1. 中断异常现场保存和恢复。
  2. 块原子相关部分。
  3. sysget/sysset功能实现，但bstate.in/out 数据结构未定义，暂时不可用。
  4. add_tpc, add_bpc, 未加测试用例。
  5. wfi指令待检查。
  6. 系统指令编码到了block head的set mask域段，需要改成系统微指令。


版本号：v0.2
-------------
发布时间：2022-02-25
说明：该版本基于BlockISA v0.11版本

已实现：

  1. 标准标量块指令，对应基础指令集。
  2. 全部系统指令。
  3. 中断异常现场保存和恢复。
  4. 原子块指令。

已知遗留问题：

  1. 系统指令目前是直接编码到块头里的。
  2. 现场保存和恢复的测试用例使用一条辅助测试指令触发的现场保存到bstate.out，该
     指令后续会删除。

  3. 现场保存和恢复需要把当前bpc保存到mepc，但是这样会破坏riscv的寄存器，需要OS
     做相应的修改，所以在commit 701e8fb8中把这个逻辑临时注释掉。随后和OS联调需要
     去掉这个注释。

  4. 原子块指令没有测试访存缺页的场景，需要OS配合。同时，原子指令需要增加更多的
     的测试用例，目前的测试是对一个64bit内存做原子加操作。由于原子块指令需要继续
     设计，我们等设计好后再继续，下一个版本先用riscv类似的单指令原子指令支持。

  5. ecall指令对pc指令做了一个hack，使的返回pc可以指向下一个顺延的block head，
     和OS联调时需要修改这里。

版本号：v0.3
-------------
发布时间：2022-03-22
说明：该版本基于BlockISA v0.12版本

已实现：

  1. v0.12里除了lr/sc的所有特性。
  2. 使用3.21编译器版本, 链接简易start.S, 编译运行简单测试程序OK。

已知遗留问题：

  1. 现场保存和恢复的测试用例使用一条辅助测试指令触发的现场保存到bstate.out，该
     指令后续会删除。

  2. 现场保存和恢复需要把当前bpc保存到mepc，但是这样会破坏riscv的寄存器，需要OS
     做相应的修改，所以在commit 701e8fb8中把这个逻辑临时注释掉。随后和OS联调需要
     去掉这个注释。

  3. 原子块指令没有测试访存缺页的场景，需要OS配合。同时，原子指令需要增加更多的
     的测试用例，目前的测试是对一个64bit内存做原子加操作。由于原子块指令需要继续
     设计，我们等设计好后再继续。

  4. ecall指令对pc指令做了一个hack，使的返回pc可以指向下一个顺延的block head，
     和OS联调时需要修改这里。

  5. v0.12里的lr/sc特性还没有实现，该特性后续根据手册和内核的需要实现。

版本号：v0.4
-------------
发布时间：2022-06-28

说明：

        | 该版本基于BlockISA v0.12版本(LARM commit id: 2a5d115a9), 
        | 同时作为LinxV150项目阶段一发布版本，版本号LinxISAV150B001_20220625。
        | 该版本和内核、OS以及编译器相同版本号版本同时发布。

已实现：

  1. v0.12里的所有特性

已知遗留问题：

  1. 块内响应中断时，内核会概率性崩溃。运行qemu时加上-enable_delay_block_intr可以
     禁止块内响应中断，上述问题不会发生。

  2. 使用block ISA rootfs，qemu system mode运行时会出现uecall返回地址概率性出错。
