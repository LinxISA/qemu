===========================
内存块指令b.mpush和b.mpop测试方案
===========================

-------------------------
b.mpush
-------------------------

- 指令介绍:内存压栈(Block Memory Push),将指定的多个寄存器(BGET掩码)中64bit的数据,
  从低位到高位依次写到目标寄存器所指的连续内存空间中,同时递增目标寄存器的值。

- *测试思路:主要测试三种情况,写入两个寄存器的值;写入寄存器和目标寄存器重复;除了sp和ra以外的所有寄存器
    + 读取两个寄存器的值:创建数组src和des,将数组src的值作为函数参数传入a0,a1,同时将
    des传到a2作为目的寄存器的值。执行b.mpush函数,将a0和a1传入des数组。最后比较src
    和des数组中的值
    + 读取寄存器和目标寄存器重复:创建数组src和des2,将数组src的值作为函数参数传入a0,
    a1,同时将des传到a0作为目的寄存器的值。执行b.mpush函数,将a0和a1传入des数组。最
    后比较src和des数组中的值
    + 读取除了ra和sp以外的寄存器:创建数组src16和des16,汇编中通过set.g吸入a0-a7,
    s0-s5,同时将des16传到a0作为目的寄存器的值。执行b.mpush函数。最后比较src16和
    des16数组中的值

-------------------------
b.mpop
-------------------------

- 指令介绍:内存弹出(Block Memory Pop)从源地址寄存器对应内存地址连续读取 64bit 数据,
  从低到高按序写回到指定寄存器(BSET掩码)中,同时源地址寄存器递增。

- *测试思路:主要测试三种情况,读取两个寄存器的值;读取的寄存器和目标寄存器重复;除了sp和ra以外的所有寄存器
    + 写入两个寄存器的值:创建数组src和des,将数组src的首地址作为函数参数传入a0作为
    目的寄存器的值。执行b.mpop函数,将数据写入数组的内存空间。再将数组des的首地址作
    为函数参数传入a0作为目的寄存器的值,执行b.mpush函数。将数据读出,最后比较src和
    des数组中的值。
    + 其余的测试情况和写入两个寄存器的思路基本一致
