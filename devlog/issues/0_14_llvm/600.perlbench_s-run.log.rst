************************

介绍
======

SpecInt2017测例中，600.perlbench_s子项在用LLVM-v0.14编译器编译后，在qemu上运行得到的
输出log与SpecInt标准输出文件（x86环境下构建）不一致
（在保证运行命令及输入文件与标准相同的基础上）。

本篇就是用来记录 600.perlbench_s 分析的情况。

对比发现x86输出和标准输出也有差异，且与llvm输出差异位置一致。
然后考虑到可能是运行的输入问题，缺少隐藏的配置文件，所以将x86的可执行程序拷到标准执行的目录下运行。
得到输出后与标准输出对比发现是一致的。
然后进一步将llvm可执行程序放到标准目录环境下运行，得到的输出与标准输出也一致。
结论：问题解决。同时发现了之前运行测例时缺少隐藏的输入文件，以后运行时在标准环境下运行。
