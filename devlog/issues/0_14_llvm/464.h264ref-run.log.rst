介绍
======

SpecInt2006测例中，464.h264ref子项在用LLVM-v0.14编译器编译后，在qemu上运行得到的输出log与
SpecInt标准输出文件（x86环境下构建）不一致（在保证运行命令及输入文件一致的基础上）。

本篇就是用来记录 464.h264ref 分析的情况。

结合上面三个输出发现：此测例通过llvm、riscv和arm编译后的程序运行得到的输出是一致的，
与标准输出不一致是架构不同所致。

补充
在后续v0.16和v0.20版本的Specint联调中，通过直接对比bisa(llvm编译器)编译后输出与riscv
以及arm编译后的输出，发现是不完全一致的。
证明bisa编译后程序还是存在错误的，所以在后续的版本中需要继续跟踪定位，
定位过程和问题原因在v0.16版本的联调记录中详细描述。
