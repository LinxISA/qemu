问题描述
==========
525.x264_r 反汇编 header 类型错误

问题分析
==========
20230402

测例报错：“x264 [error]: could not open output file”。在源码中搜索，确定到在
Parse() 函数内，看到它是在一个 if 判断内::

    if( output.open_file( output_filename, &opt->hout ) )       （1）
    {
        fprintf( stderr, "x264 [error]: could not open output file `%s'\n",
                    output_filename );
        return -1;
    }

即 output.open_file 的返回值不为 0 的时候，就会报错；往上找，找到 output 是在
select_output 内赋的值，添加打印，可以得到::

    output = raw_output;                                        （2）

继续看 raw_output，在它的 open_file 函数里面添加打印，再跑一下，发现函数内添加的打印
没有输出，即上面的语句（1）没进去；接下来看汇编::

    .L.str.12:
    .asciz	"x264 [error]: could not open output file `%s'\n"

根据此字符串往上找，找到 if 判断对应的反汇编块为::

    .LBB0_147:
        bstart .LBB0_147.bstart
        b.std
        bnext.fall
        bget	sp, a0
        bset	a0, a1
        bstop .LBB0_147.bstop
        .pushSection	.text.body
    .LBB0_147.bstart:
        ld	[sp, 176]
        set	t#1, a0
        ld	[a0, 0]
        const	328
        add	sp, t#1
        set	t#1, a1
        ld	[sp, 192]
        set	t#1, a0
        setc.tgt	t#6
    .LBB0_147.bstop:
        bend
        .popSection
    .LBB0_148:
        bstart .LBB0_148.bstart
	    b.std
	    bnext.cond	.LBB0_151
	    bget	a0
	    bstop .LBB0_148.bstop
	    .pushSection	.text.body
    .LBB0_148.bstart:
        setc.eqi	a0, 0
    .LBB0_148.bstop:
        bend
        .popSection
    .LBB0_149:
        bstart .LBB0_149.bstart
        b.std
        bnext.call	fprintf
        bget	sp
        bset	ra, a0, a1, a2
        bstop .LBB0_149.bstop
        .pushSection	.text.body
    .LBB0_149.bstart:
        lconst	stderr
        ld	[t#1, 0]
        set	t#1, a0
        lconst	.L.str.12
        set	t#1, a1
        ld	[sp, 192]
        set	t#1, a2
    .LBB0_149.bstop:
        bend
        .popSection

在此处它的 bnext 为 fall 块，微指令有 setc.tgt，块头与微指令不符，编译器确认是一个
header类型错误，经编译器修改，执行通过，验证正确。
