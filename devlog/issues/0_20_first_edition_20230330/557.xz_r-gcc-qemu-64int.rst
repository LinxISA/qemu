557.xz_r 段错误问题分析
=======================
作者:hwx1084147(黄浩富)

问题描述
-----------------------
557.xz_r 在运行过程中发现段错误问题

问题分析
-----------------------
20230328

qem在运行557测例的memcpy时发生段错误，原因是测例使用的标准输入文件，该文件解压缩
后的大小超过6G，其比特位数超过32位，测例中源码的memcpy的size大小是uint64_t的，所
以x86执行的时候size的大小始终在64位范围内，不会报段错误。但是qemu中memcpy的实现
里面，size为int型，占32位，而输入文件的size中远远大于32位，超出qemu的识别范围，
导致段错误的发生。将qemu中memcpy实现的size改为uint64_t之后，再次运行测例，测例
验证通过。
